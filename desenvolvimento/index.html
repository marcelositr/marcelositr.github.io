Uma preferência recorrente

Local-first, quando faz sentido

Vários dos projetos acabam seguindo uma mesma direção: manter os dados próximos do usuário, reduzir dependências externas e deixar claro o que o software realmente faz.

Isso aparece no Daymark e no MeliponarioManager, por exemplo, mas também na forma como ferramentas de rádio e sistemas auxiliares são pensados. Nem todo projeto precisa de uma conta, uma nuvem ou uma infraestrutura permanente para ser útil.

GNU/Linux

O sistema também faz parte do laboratório

GNU/Linux não aparece aqui apenas como plataforma de desenvolvimento. É parte do ambiente em que testo ideias, automatizo tarefas, monto serviços e tento manter as coisas suficientemente transparentes para saber o que está acontecendo.

O i3 Starterpack é uma expressão bem direta disso: uma configuração pessoal que reúne as escolhas que fazem sentido para meu uso diário no Debian.

Processo

Antes de ficar bonito, precisa funcionar

Gosto de testar primeiro, documentar as decisões e só depois pensar em acabamento. Testes automatizados, documentação e ferramentas de diagnóstico fazem parte do projeto tanto quanto a interface final.

É também por isso que alguns repositórios podem parecer maiores do que a aplicação em si. O objetivo é deixar o caminho reproduzível para quem precisar entender, instalar, testar ou continuar o trabalho.
